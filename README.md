# 捞捞：大学生的 AI 学习工作台

> **ZJUT HACK 2026 · AI × 软件应用赛道 · 捞捞队**
> 在线体验：<https://www.laolaokechengbiao.cn>　·　评审测试账号 `ceshi` / `ceshi12345678`（各端通用，也可以不登录直接体验）

群里的通知自动变成日程；课件、编程、讲题有 AI 帮手；还用同学们闲着的电脑，训练我们自己的模型。

## 我们想解决的问题

| 问题 | 现在大家怎么办 | 捞捞怎么做 |
|---|---|---|
| 作业、考试、调课散在好几个班级群里，一刷就没了 | 截图、记备忘录，靠记性 | 粘贴群消息，AI 整理成带时间、地点、科目的日程，到点提醒 |
| 做 PPT、学编程、刷题卡住了，身边没人马上讲明白 | 搜网页、等老师答疑 | 捞小智一个对话里讲题、做 PPT、办事；捞捞编程看不懂报错直接问 |
| 学生团队买不起大显卡，长期租云 GPU 也贵 | 只能调别人的接口，自己的模型做不起来 | 捞捞算力把同学们闲着的电脑连成一台「训练机」，训练、考试、发布全自动 |

## 核心技术方案

**AI 整理：越用越懂你的班。** 本地规则先解析时间、地点、科目和「提前交」这类口语（`parse.js`，不调用大模型）→ 拿不准的交给大模型抽取结构化字段 → 用户核对修正 → 修正沉淀成本班共享的整理规则。

**捞小智：小模型也要答得可靠。** 底座是通义千问 Qwen3-VL-4B（量化后 2.5G，在学生的笔记本上跑）：
- 先查资料再回答：每句标出处，说出口前逐句核对「有据 / 无据 / 矛盾」，资料里没有就说没有（`pptassist/core/ground.js`）；
- 改 PPT 用的就是捞捞PPT助手自己那套工具（`pptassist/core/agent.js`、`pptedit.js`），能插 PowerPoint 原生公式、换版式、撤销；
- 回答在思维导图里以导图的形式给出；本机提供 OpenAI 兼容接口，别的软件也能接。

**捞捞算力：一台停了，下一台接着算。**
- 租约 + 存档接力：2 分钟没消息就换电脑，从最近的存档接着算；只派给真正空着显存的电脑；
- 配方签名：别人电脑上跑的代码必须由管理员私钥签名（Ed25519），不对就不跑；
- 对主人友好：按显卡温度调节训练强度，主人一用电脑就让出显卡，夜间静音慢算；
- 自动训练流水线：程序出题、程序判对错造数据（数学、照资料回答、口语对话、改 PPT、看图反推）→ QLoRA 训练 → 固定考卷上原版和新版同时考、逐题配对比，有 90% 把握真的变好才发布 → 考过的合进底座，一层层让底座本身变强；
- 客户端新版分批推送：先一台试，没问题再推一半、推全部；出错多就停推、已经装上的自动退回。

数据流向：`班级群消息 / 课件 / 照片` → 本地规则 + 本地或云端模型 → `结构化日程 / 改好的 PPT / 回答` → 用户修正 → 回流成整理规则和训练数据 → 捞捞算力训练 → 考过了自动换上新模型。

## 已实现功能（现场能演示）

1. 粘贴一段班级群消息，自动拆成几条带截止时间、地点、科目的日程；拍课表截图导入整学期课表。
2. 捞捞教练：按截止远近和事项类型告诉你「现在先做这个」，到点提醒；网页、小程序、安卓、电脑版数据实时同步。
3. 捞小智：讲一道数学题（一步一步）；做一份 8 页左右的 PPT 再说「第 3 页改成两栏对比」「整份换成绿色」；拍一张课件照片还原成能改的一页；打电话式语音对话。
4. 捞捞PPT助手：上传照片生成 Q版形象，配上声音在 PPT 里开讲；拍照插公式。
5. 捞捞编程：写 C 程序、F5 运行，报错问本地模型。
6. 捞捞算力控制中心：看几台电脑一起训练，关掉一台、另一台从存档接着算；训练曲线、考试成绩、模型版本、每日简报。

## 隐私与合规

- 老师的照片、声音只在老师自己的电脑上用；上传前要先确认授权，「一键清除」随时撤回。
- 所有 AI 生成的讲解视频画面上一直有「AI生成」字样，文件里写了隐式标识（按《人工智能生成合成内容标识办法》、GB 45438-2025）。
- 训练用的人物照片全是 AI 画的虚构人物；演示用的教务数据是虚构的。

## 技术架构

- **客户端**：网页（原生 JavaScript，离线缓存，可安装为桌面应用）、微信小程序、安卓原生 App（Kotlin）、Windows 电脑版（Electron），共用同一套接口和核心规则。
- **后端**：云端 PostgreSQL，业务逻辑以数据库函数实现，经 REST 接口调用；课表识别、聊天截图识别、群消息整理等 AI 服务部署在扣子平台。
  后端代码涉及服务密钥，未放入本仓库；评审如需查看，请联系团队负责人提供只读访问。
- **AI 整理流程**：本地规则先解析 → 拿不准的交给大模型（云端或本地模型）抽取结构化字段 → 用户核对修正 → 修正结果沉淀为本班共享的整理规则。
- **安全**：接口最小权限白名单、数据库行级安全隔离班级数据、登录设备管理、异常登录自动退出、接口限流。
