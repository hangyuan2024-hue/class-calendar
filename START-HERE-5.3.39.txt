捞捞课程表 5.3.39 更新包 — 使用说明（请先看这个）
================================================

这个压缩包里有什么？
- android/ 文件夹：手机 App 的最新源代码
- .github/workflows/preview-android.yml：让 GitHub 自动打包安装包的设置
- 本说明文件

怎么上传到 GitHub（照做即可）：
1. 把这个 ZIP 解压到电脑上任意位置。
2. 打开解压出来的文件夹，选中里面所有内容（android 文件夹、.github 文件夹、本说明）。
3. 复制它们，粘贴到你的仓库文件夹（hangyuan2024-hue/class-calendar）的
   最外层，也就是和原来 android 文件夹并排的位置。
   如果电脑问"是否覆盖/合并"，全部选"是/替换"。
4. 打开 GitHub Desktop，左边会看到一堆改动，
   在左下角输入框写一句说明（比如"5.3.39 时间轴可收起+自动刷新"），
   点左下角蓝色按钮 "Commit to main"。
5. 点上面的 "Push origin" 上传。

上传后怎么拿到手机安装包：
1. 在浏览器打开你的仓库网页，点上面的 "Actions" 标签。
2. 等最新一次打包跑完（绿色勾，一般几分钟）。
3. 点进去，往下找到 "Artifacts"，下载里面的 APK 文件。
4. 把 APK 发到手机上，点击安装（不用卸载旧版本）。

本次更新了什么：
1. 首页"今日时间轴"可以收起/展开：点标题右边的"收起"，
   只留一行汇总（几项安排、还剩几项、下一项是什么），点这行可再展开。
2. 班级相关页面（班级、班级墙、排行、成员、分组等）和"贡献名单"
   会自动刷新：打开时、切回 App 时、停留期间每 1 分钟一次，
   不用再手动点刷新按钮。

已验证：72 项自动测试全部通过，安装包签名和对齐检查通过。
还没验证：真机实际安装、真实账号双端同步、国产手机提醒。
