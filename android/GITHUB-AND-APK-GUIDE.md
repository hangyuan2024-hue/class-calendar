没有替你上传 GitHub，也没有修改或部署扣子数据库；不能保证数据“绝对正确”。

一、手机安装（先不要卸载原来的 App）
1. 下载单独的 ClassCalendar-5.3.36-preview.apk。
2. 手机“文件管理”→“下载”→点 APK→安装。
3. 提示禁止安装时，点设置，允许当前文件管理器安装未知应用，再返回安装。
4. 打开“捞捞课程表”，我的→关于，核对版本 5.3.36-preview。
5. Android 7.0 或更高可安装；体验包与正式包可以并存，不自动复制正式包本地数据。
6. 用原账号登录读取云数据；先保留旧 App 并导出备份。
7. 若签名不一致，不要直接卸载；先备份。GitHub 与本次安装包的测试签名可能不同。

二、你只需要把源码包内容放在仓库根目录
1. 下载 ClassCalendar-GitHub-Overlay-5.3.36.zip→解压。
2. 解压后直接看到 android、app.js、guard.js、.github、START-HERE.txt。
   不要另加一层同名文件夹；目标必须是 class-calendar/android/app。
3. 先备份你的整个 class-calendar 文件夹。
4. 全选解压内容（包括隐藏的 .github）→复制进现有 class-calendar 根目录。
5. 选择合并文件夹、替换同名文件；不要删除原网站其他文件。
6. app.js、guard.js 必须替换根目录同名文件；这是新增网站筛选与外观同步衔接。
7. .github/workflows/preview-android.yml 是体验打包流程，保留原正式发布流程。
8. 不需要复制 node_modules、build、签名文件或改数据库；包中没有这些文件。

三、上传 GitHub（电脑操作）
1. 安装 GitHub Desktop：https://desktop.github.com/，登录你的 GitHub。
2. 打开 https://github.com/hangyuan2024-hue/class-calendar 。
3. 绿色 Code→Open with GitHub Desktop→Clone。
4. GitHub Desktop→Repository→Show in Explorer（Mac 为 Show in Finder）。
5. 把第二部分的文件复制进这个根目录。
6. 回 GitHub Desktop，查看 Changes，填写 Summary“今日安排与手机页面改版 5.3.36”。
7. 点 Commit to main（或当前分支）→Push origin。
8. 检查 Changes 不包含 release.jks、local.properties、密码或自动生成 build。

四、生成体验安装包
1. 仓库→Actions→左边 Build Android APK。
2. Run workflow→选上传的分支→绿色 Run workflow。
3. 等绿色对勾→打开记录→下方 Artifacts→ClassCalendar-5.3.36-preview。
4. 下载 ZIP→解压→里面 APK 传到安卓手机，按第一部分安装。
5. 若失败，点红色步骤，截图最后的错误；本流程不需要正式签名密码。
6. 这是体验版流程，不会自动发布到应用商店，也不替代你原来的正式签名。

五、怎么查看效果图片
1. 下载 ClassCalendar-Design-Previews-5.3.36.zip→解压→点图片。
2. 每张图片顶部都说明：示例数据设计效果，非安卓实机截图。
3. 网站图片来自实际网站页面代码的受控本地运行，使用注入样例；并非线上账号。
4. 手机图片来自浏览器排版预览，与 APK 可能有差异，不能替代真机验收。

六、按顺序验证新功能
1. 首页选全部：逐条显示时间/全天、事项名称、地点、完成状态，滑到底看完所有安排。
2. 添加同一天至少 8 个事项与数门课，查看全部、只看课程、只看其他事项。
3. 勾选任务，再重新打开页面，看完成状态保留。
4. 加一条昨天到期未完成任务与一条无日期任务，看逾期/未定日期分区。
5. 首页/课表/班级/设置右下角加号分别打开，检查操作不同；课表添加/导入，班级创建/加入。
6. 我的→外观：选择学生、教师、职场风格；关闭与网站同步配色，再选配色，网站不应变化。
7. 再开启同步，用同一账号在两端改配色/模式、刷新查看；这是仍需实测的步骤。
8. 更新网站后重新打开并刷新；首页应有全部/只看课程/只看其他事项。
   如果还是旧网站，关闭旧标签再打开；浏览器与网站离线缓存可能延迟更新。
9. 学生账号建班→检查班级码/管理员，再用另一个账号加入并审批；这是仍需实测的步骤。
10. 手机设置页打开通知/电池/精确提醒设置，授予需要的权限，锁屏等待提醒。
    小米/华为/OPPO/vivo 等还可能要求手动开启后台运行/自启动；不保证厂商杀后台后准时提醒。
11. 捞捞伙伴可拖动、轻点查看提示；外观页可关闭。检查拖到边缘时不影响列表与按钮。
