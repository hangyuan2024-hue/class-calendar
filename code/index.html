刚学编程，最难的往往不是代码，是配环境：装 MinGW、配 PATH、装 Python、装 JDK……捞捞编程把这些都装好了。装完打开，选一种语言，写完按 F5 就能运行；看不懂报错，点一下问捞捞，电脑里的本地模型给你讲，不联网也能用。

成绩.c — 捞捞编程▶ 运行 F5
#include <stdio.h>
int main() {
    int score;
    printf("输入成绩：");
    scanf("%d", score);   // ← 少了 &
    printf("%s\n", score >= 60 ? "及格" : "加油");
}
⚠ 第 5 行：scanf 的第 2 个参数应该是 int *，你给的是 int
🐟 捞捞：scanf 要知道「把读到的数放在哪」，所以要给它变量的地址。试试在 score 前面加一个 &，再按 F5 看看～

04 / FAQ

常见问题

为什么安装包这么大？

里面装了 C / C++ 编译器（GCC）、Python，还有一个能在你电脑上运行的 AI 模型（通义千问 Qwen2.5-Coder 1.5B，约 1 GB）。装好以后写代码、问问题都不用联网。

问捞捞要联网吗？会把我的代码传上去吗？

不用联网，也不上传。模型就在你的电脑里运行，代码只存在你自己的电脑上（默认在「文档 / 捞捞编程」文件夹）。

要登录吗？

不登录也能用全部功能。登录捞捞调度账号（和捞捞课程表、捞捞学习同一个账号）后，练习进度会存到账号里，换电脑也接得上。

Java、JavaScript、Go 怎么装？

在左上角选这门语言，第一次运行时会提示安装，点一下就自动下载装好（优先用国内镜像），以后直接用。不会改你电脑上的其他设置。

电脑上已经装了别的编译器，会冲突吗？

不会。捞捞编程用的是自己带的那一套，不改系统的 PATH，也不影响你装过的 Visual Studio、Dev-C++ 等。
