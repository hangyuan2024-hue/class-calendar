# 捞捞课程表 · Windows 电脑版 3.2

独立的电脑软件，不是网页套壳：界面按电脑屏幕设计，数据存在本机，和网站、手机用同一个账号实时同步。

## 3.2 改了什么

- **配色和网站一样**：设置 → 外观 →「配色」换成网站那 16 套（天空蓝、樱花粉、蜜桃……石墨）加「我的配色」（主色 + 点缀色自己调）。存在同步数据 `ui_palette_v1` 里，网站上换了，电脑版也跟着变，反过来也一样。网页风格下底色、问候卡片也会带一点主色（和网站一样）
- **侧栏名字和网站一致**：今日 → 首页，月历 → 日历，课内学习 → 学习，AI 助手 → 问答，打卡 → 成长，工具箱 → 工具，成员 → 班级成员，元宇宙 → 元宇宙空间（「事项」「课程表」「思维导图」这些网站没有单独入口的保留原名）
- **首页时间轴重做**：上面一条是课，下面是有时间点的事（小卡片：时间 + 名字，作业带「截止」）；按真实宽度把挨得近的事错开成几行，靠右的往左展开，不会被切掉；已经过去的时间画斜线灰掉；「现在」的时间放在刻度上，刻度挤不下自动隐藏；放不下的显示「还有 N 件」。卡片变窄（窗口小、开着详情栏）时上下排
- **修好：点开时间轴上的事，右边详情栏按钮点不动、鼠标放上去一直闪**。原因是详情栏每画一次都会去读附件数量，数量一报上去又让界面整个重画，详情栏就以每秒几十次的速度不停重画。现在数量没变就不通知，详情栏内容没变也不重画

## 3.1 改了什么

- **局域网互传**：记事时勾「🔒 只存在这台设备」，这件事不上传云端；同一账号的电脑、手机、网页在同一个 Wi-Fi 里时，用 WebRTC 点对点直接传（和网站 `live.js` 同一套协议，网页、手机、电脑之间都能互传；服务器只帮忙交换连接信息，不走外网中转）。设置 →「同步和数据」里能开关、看连上了几台设备；标题栏右上角连上时显示「局域网 N」
- **两种界面风格**：设置 → 外观 →「界面风格」。「电脑版风格」是 3.0 的课表纸 + 课铃线；「网页风格」和网站「清爽」外观一样：白色大侧栏、浅青绿选中块、「记一件事」大按钮、一张张白卡片。功能、快捷键完全一样，随时切换
- **侧栏重新分组**：常用的今日 / 课程表 / 作业 / 事项 / 月历放最上面；学习、班级、成长三组可以点组名收起（收起后组名旁边显示要紧的数量，当前页面所在的那一项还在）；「整理群消息」挪到班级墙旁边
- **设置页加了目录**：左边一列，点了跳到那一组；分组顺序改成外观、提醒、同步和数据……账号放最后
- 修好：设置页里点主色等按钮会把主题改回「跟随系统」；网站上课内学习的考核点「✓ 完成」「隐藏」「备注」没反应（网站 `app.js`、手机左滑 `ux.js`）

## 3.0 改了什么

**新界面**
- 标题栏下面一条**课铃线**：今天的节次一段一段排开，上过的填满，正在上的那节有橙色走针；标题栏同时写着「正在上 线性代数 · 还剩 18 分钟」
- **今日**页最上面是课铃时间带：左边是「接下来最该关注的一件事」（和捞捞、网页版同一套智能排序）和倒计时，右边是一天的时间轴（课是色块、有时间点的事是小旗、竖线是现在）
- 任何页面点一件事，右边滑出**详情栏**，不用跳页面；深色模式重新配色；主色默认和网站一样的青绿

**修好的问题**（以前会导致数据出错）
- 网站 10 月新加的 9 类同步数据电脑版不认识，会直接丢掉、而且不会再补拉 → 现在全部认识；以后网站再加新类型，电脑版也会原样保存
- 电脑上保存课程表会把网站上记的调课 / 调休冲掉 → 现在会带上
- 时间改成和网站一样按北京时间、用服务器时间校准；同步从 5 分钟一次改成实时（几秒内）

**和网站对齐的功能**：课内学习、思维导图、云宠农场、元宇宙工具箱、随机抽签器、错题记录本、调课 / 调休、事项云端附件、过期 2 周自动删除（可推迟）、编辑（仅自己）、自己记的作业、整理群消息时「只保存给自己」、学校 / 单位、注册、找回密码、日历「只看课程 / 不看课程」开关、管理员后台入口

**电脑版独有**（新加的）：任意页面单独开窗口（课程表、思维导图放到第二块屏幕）、导出 Excel 表格（事项 / 课程表）、单条事项加到日历、把文件拖到事项上传云端附件、附件另存到电脑、桌面小窗里也有课铃线

原来就有的电脑版功能都还在：托盘常驻提醒、Ctrl+Alt+空格快速记事、桌面小窗、离线 AI、复制群消息自动识别、截图导入课表、课表壁纸、导出 PDF / 图片 / 打印、作业挂本机文件、倒数日、每周学习报告、每天自动备份、早安简报、专注和上课免打扰、白噪音、任务栏按钮和角标、跳转列表、Ctrl+K 命令面板。

## 网站更新了，电脑版怎么跟上

电脑版里有一部分代码直接用网站的那份，**打包时自动从网站拷最新版**（`scripts/sync-web.js`）：

| 网站文件 | 电脑版里用来 |
| --- | --- |
| `parse.js`、`island-core.js`、`config.js` | 整理群消息的规则、捞捞的智能排序和问答、服务器地址 |
| `study.js` `mindmap.js` `farm.js` `metaverse-v3.js`（和对应的 css） | 课内学习、思维导图、云宠农场、元宇宙工具箱整页 |
| `sandbox.html`、`plugins/random-draw.html`、`plugins/error-notebook.html` | 工具箱的隔离间、两个内置工具 |
| `fonts/`、`schools-2026.json` | 标题字体、本科院校名单 |

所以改了这些网站文件，GitHub Actions 会**自动重新打包电脑版**（`.github/workflows/desktop.yaml` 里列着）。这几个模块用到的网站全局变量（`$`、`currentUser`、`save`、`Sync`……）由 `renderer/webshim.js` 换成电脑版的数据；网站模块如果开始用新的全局变量，在那里补上就行。

其余页面（今日、课程表、事项、作业、月历、班级墙、规划……）是电脑版自己写的，网站这些页面改了新功能，需要在电脑版里对应改一下。

## 文件

```
desktop/
  main.js            主进程：窗口、托盘、提醒、快捷键、专注计时、AI、实时同步、导出
  preload.js         界面能调用的功能清单（界面拿不到登录令牌）
  core/              数据和逻辑：登录注册、同步、提醒、日期识别、调课规则、AI
  renderer/          界面：index.html（主窗口）、quick.html（快速记事）、mini.html（桌面小窗）、brief.html（早安简报）
    base.css         设计系统（颜色、字体、组件）
    v3.css           新外壳和重做的页面
    skin-web.css     「网页风格」皮肤（<html data-ui="web"> 时生效）
    lan.js           局域网互传（WebRTC）
    webshim.js/.css  网站模块的转接头
    web/             从网站拷来的模块（自动生成，不进 git）
  scripts/sync-web.js  从网站拷代码
  test/              测试：node test/core.test.js；界面可以用 test/mock-cc.js 在普通浏览器里预览
```

## 怎么出安装包

改了 `desktop/` 里的文件（或者上面表里的网站文件）并上传到 GitHub 后，Actions 里的「电脑版」会自动打包（大约 10 分钟），发布到仓库的 Releases。下载地址固定是：

https://github.com/hangyuan2024-hue/class-calendar/releases/latest/download/LaolaoKechengbiao-Setup.exe

自己在电脑上打包：装好 Node.js 20，在 `desktop` 文件夹里运行 `npm install`、`npm run dist`（会先自动运行 `npm run sync-web`）。
