# 捞捞课程表 · Windows 电脑版

独立的电脑软件，不是网页套壳：界面专门按电脑屏幕重新设计，数据存在本机，和网站、手机用同一个账号自动同步。

## 有什么

| 页面 | 能做什么 |
| --- | --- |
| 今日 | 问候、一句话记事、今天的课（正在上哪节、还剩几分钟）、要做的事、统计、这一周、班级墙 |
| 课程表 | 整周课表铺满屏幕，红线标出现在的时间；点一节课看详情和相关作业；← → 翻周 |
| 事项 | 左边筛选、中间一张表、右边详情和备注；Shift/Ctrl 多选、批量完成；全键盘操作 |
| 月历 | 一整月铺开；自己记的事直接拖到别的日子；双击某天新建 |
| 班级墙 | 看通知和讨论，发帖 |
| 专注 | 番茄钟，后台计时，关掉窗口也不停；最近 14 天记录 |
| AI 助手 | 在电脑上运行的通义千问 1.5B，知道你的课表和作业；不联网也能用 |
| 设置 | 提醒时间、深色模式、开机启动、快捷键、导出 .ics 到日历 |

另外：
- **右下角提醒**：上课前、事项开始/截止前、每晚 8 点汇总明天
- **托盘常驻**：关掉窗口缩到右下角，继续提醒
- **Ctrl+Alt+空格**：在任何软件里弹出小框，一句话记一件事（「明天下午3点交实验报告 @B302」）
- **桌面小窗**：今天的课和待办，一直浮在最上面
- **Ctrl+K**：搜索所有事项、课程，执行命令

## 文件

```
desktop/
  main.js        主进程：窗口、托盘、提醒、快捷键、专注计时、AI
  preload.js     界面能调用的功能清单（界面拿不到登录令牌）
  core/          数据和逻辑：登录、同步、提醒、日期识别、AI
  renderer/      界面：index.html（主窗口）、quick.html（快速记事）、mini.html（桌面小窗）
  test/          测试（node test/core.test.js）
```

## 怎么出安装包

改了 `desktop/` 里的文件并上传到 GitHub 后，Actions 里的「电脑版」会自动打包（大约 10 分钟），
发布到仓库的 Releases。下载地址固定是：

https://github.com/hangyuan2024-hue/class-calendar/releases/latest/download/LaolaoKechengbiao-Setup.exe

网站的服务器地址（config.js）和标题字体（fonts/）打包时会自动放进去，不用复制。
