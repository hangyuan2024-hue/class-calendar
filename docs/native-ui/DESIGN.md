# 原生界面与八套皮肤的设计维护

## 完整配色

`CampusTheme` 是页面、导航、原生装饰和皮肤缩略图共同的颜色来源。每套定义背景、卡片、正文、说明、主色、首页渐变和夜间星光，共八套：晴空蓝、森野绿、樱花粉、暖杏橙、鸢尾紫、海盐青、深海赛博、曜石黑。

浅色背景使用低饱和度的蓝、绿、粉、杏、紫和青，配合明确的深色正文；深色使用青光深海与暖金石墨两种方向。色彩参数及实际计算结果在 `checks/results/palette-tokens.json`。八套预设中，已列出的正文、辅助文字、主色文字和渐变文字对比值均不低于 4.5:1；这项参数检查不等于整个应用通过无障碍认证。

开启系统深浅色时，浅色家族转换为深色背景，并使用对应的亮色主色。元宇宙始终采用深色表面，继续继承所选配色的星光。原生日期、时间、选择和确认弹窗使用 `native_dialog_palettes.xml` 中的八套浅色 / 深色样式。日期弹窗额外应用仅覆盖最小宽度的原生主题，让标题与日历按自身尺寸对齐，保留整套配色继承。

皮肤和主色沿用 `ui_skin_v1` / `ui_palette_v1`，通过一次 `CampusStore.batch` 一起保存，再进入原有同步队列。未知配色与无效颜色安全回退；旧偏好、自定义主页、背景照片和学习记录保持兼容。

## 布局与控件

页面标题 24sp、区块标题 17sp、卡片标题 14—15sp、说明 11—12sp，随系统字体大小缩放。内容间距按 8 / 12 / 16 / 20 / 24dp 排列。普通卡片圆角 22dp、主卡 26dp，分组工具使用整块卡片和细分隔线，减少重复边框。

顶部为不透明原生栏，按钮触控区至少 48dp；右上角提供常驻调色板入口。底部使用不透明圆角导航，限制最大宽度并居中。手机内容边距 16—20dp，平板内容最大 760dp，编辑表单最大 580dp。大于 125% 字体时，多数工具网格改为单列；首页主操作纵向排列，装饰占用减少。六个正常字号分类等分宽度，确保末项可见；大字分类可横向滚动。

首页课程长名称最多占两行，完整名称仍可在详情和课程清单读取。统计由已保存数据计算，装饰插画不虚构用户内容。分组列表、常用入口和专注 / 成长卡构成不同的信息层次。

表单保留固定取消 / 保存区域，输入内容可滚动；错误提示置于标题下，错误字段红色描边和读屏描述。原生日期、时间与选择器继续可用。周课表提供可横向滑动的真实课程网格和原生完整清单。

## 维护入口

| 文件 | 职责 |
| --- | --- |
| `CampusTheme` | 八套完整配色、深浅色解析与颜色混合 |
| `CampusSkins` | 原生皮肤画廊、立即应用、自动深浅色与保存 |
| `CampusUi` | 共享卡片、分组列表、网格、按钮、表单及弹窗 |
| `CampusActivity` | 固定导航、默认首页、顶部操作与个人中心 |
| `CampusToolbox` | 34 个工具入口、搜索、分类和返回状态 |
| `CampusVisual` | 原生课程插画、数字星球、轨道与真实计时环 |
| `CampusLearn` / `CampusWorld` | 学习模块、元宇宙、经验值与徽章 |
| `CampusPhone` | 十项手机能力的分组入口 |
| `CampusHome` / `CampusCourses` | 原有自定义首页和周课表 |

沿用原生 V4 的存储、权限、业务接口、离线词库、通知与手机集成。Canvas 装饰不参与读屏焦点；业务记录与计时、经验值均使用真实保存数据。

## 构建与复核

正式构建为 Java 17、Android SDK 34、Gradle 8.9，执行 `gradle -p android assembleStableRelease`，配置原 `KEYSTORE_PASSWORD`。GitHub 工作流产物版本为 `3.2.N`，N 取构建序号。

交付体验 APK `3.2.9-preview` 使用工作区的 aapt2、javac 17、d8、zipalign 和 apksigner 编译、对齐和签名，已安装运行；本地未执行原签名正式版的完整 Gradle 构建。验证脚本及报告见 `checks`。
