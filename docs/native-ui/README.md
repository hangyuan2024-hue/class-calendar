# 捞捞校园 · 全新设计多彩版

这次重新制作原生 App 的首页、工具箱、手机助手、元宇宙和个人中心，加入八套完整皮肤。原生迁移的功能、九类插件适配和十项手机能力继续保留。界面使用 Android 原生控件与 Canvas，启动进入 App 自己的工作台。

## 先安装 App

下载 **`捞捞校园-全新设计多彩版.apk`**，保存到手机，用“文件管理”打开安装。版本 **3.2.9-preview**，桌面名称仍为“捞捞原生体验”。

- 已安装之前的原生体验版：直接打开这份 APK 更新，无需卸载。包名和体验签名沿用上一版，已在模拟器核验更新前后本地记录一致。
- 只有原来的正式 App：体验版会单独安装。保留原 App，可用原网站账号登录，或通过“我的 → 数据与同步”的备份迁移入口搬入记录。
- 正式 App 仍由你的 GitHub 使用原签名构建。完整覆盖包保留原签名文件及正式构建方式。

## 上传到 GitHub：保留文件夹层级

仓库：<https://github.com/hangyuan2024-hue/class-calendar>

1. 解压 **`捞捞校园-全新设计多彩版-完整覆盖包.zip`**。里面可见 `.github`、`android`、`docs` 三个文件夹。
2. 进入仓库首页，选择 `main`，点 **Add file → Upload files**。
3. 将这三个文件夹按原有层级拖入，提交说明可填：`更新原生 App 全新界面与八套皮肤`。
4. 根目录是这三个文件夹的放置位置。不要再套一层压缩包名称文件夹，也不要把子文件全部摊平到根目录。
5. 打开 **Actions → 安卓 App**，等待最新任务绿色成功。
6. 下载任务底部的 `class-calendar-3.2.…` 产物，解压安装 `class-calendar.apk`。成功构建也会更新仓库的 `download/class-calendar.apk`。

```text
class-calendar/
├── .github/workflows/android.yml
├── android/
│   ├── app/build.gradle
│   └── app/src/main/…
└── docs/
    ├── native-v4/…
    └── native-ui/…
```

**完整覆盖包包含先前原生迁移与本次界面更新，未上传旧 V4 包也可直接使用。**覆盖包只更新上述三个目录，保留网页和电脑版文件及你已修复的网页布局。

保留仓库已有的 `android/release.jks` 和 Actions 的 `KEYSTORE_PASSWORD`，它们用于正式版覆盖更新。交付压缩包不含签名私钥。看不到 `.github` 时，在电脑文件管理器开启“显示隐藏文件”。
