# 捞捞校园 · 安卓原生设计焕新 3.3

本次更新针对安卓原生 App 的界面和排版。网站首页统计、网页样式和后端均未修改。

## 这次可以体验什么

- **今日工作台**：问候、七日日期条、下一节课、真实课程与事项数量、常用工具、接下来的安排。课程和事项可以直接打开、完成。
- **五个主导航**：今日、日程、成长、工具、我的。班级入口保留在首页常用工具和个人页中。
- **校园日程**：对齐的月历日期与安排标记，紧凑的课程时间列，日期选择和事项录入继续使用原生控件。
- **工具箱**：学习、规划、生活、手机、更多分类，实时搜索和最近使用。搜索时保留输入焦点，返回工具箱保留查询。
- **错题书架**：已有错题按学科生成原生封面，显示题目数量与掌握数量，点封面即可筛选。拍照、图片附件、复习、编辑和删除沿用原功能。
- **成长页**：真实习惯进度、完成百分比、打卡与历史热力图。已删除习惯的历史记录不会增加今天的完成数。
- **我的校园**：账号卡片、快捷色卡、完整皮肤选择、备份和原有设置。
- **统一组件**：标题层级、间距、圆角、原生图标、输入表单与按钮。顶部和底部导航使用实色背景，切换页面有轻微过渡；关闭系统动画时尊重系统设置。

这些界面由 Android 原生 View、Canvas 和本地数据组件实现，没有把网站嵌进首页。

## 十套皮肤

薄荷雾、月光白、晴空蓝、森野绿、樱花粉、暖杏橙、鸢尾紫、海盐青、深海赛博、曜石黑。

在“我的 → 外观与首页”选择完整配色，也可以在个人页点快捷色卡。支持跟随手机深浅色。元宇宙保留深色星系，并使用当前皮肤的星光颜色。

新用户默认薄荷雾；已有用户继续使用已经保存的皮肤。已有课程、事项、错题、日记、习惯和首页自定义布局继续读取原来的数据。

## 安装体验版

下载交付的 `捞捞校园-原生设计焕新版.apk`，传到手机，点击安装。桌面名称是 **捞捞原生体验**，版本为 `3.3.11-preview`。

- 安装过此前“捞捞原生体验”的用户，可以覆盖更新这个体验版。
- 已有正式“捞捞校园”的用户，体验版与正式版并存；两者是不同的安装包，体验版不会自动读取正式版的本地记录。
- 不要为了体验新版卸载已有正式 App。希望正式 App 直接更新并保留数据，请使用下面的 GitHub 构建流程。

## 导入 GitHub 并更新正式版

1. 解压交付的覆盖更新包，打开解压后的文件夹。
2. 在 `hangyuan2024-hue/class-calendar` 仓库首页的根目录，选择 **Add file → Upload files**。
3. 将包内 `.github`、`android`、`docs` 三个文件夹拖入上传区，保留完整目录结构。也可以同时上传包内说明与文件清单。不要上传最外层包装文件夹，也不要把 Java 文件散放在根目录。
4. 检查上传列表中包含 `android/app/src/main/java/com/laolao/classcalendar/CampusDashboard.java` 和 `CampusBookshelf.java`，然后提交到 `main`。
5. 打开 **Actions → 安卓 App**，等待构建成功。成功后，正式 APK 会更新至 `download/class-calendar.apk`，也可下载本次 Actions 的构建附件。

覆盖包只包含本次需要更新和新增的文件；仓库中其他安卓文件继续保留。**不需要删除原有目录，不需要上传或替换原签名文件。**

正式版继续使用仓库原有的 `android/release.jks` 和 Actions 中原有的 `KEYSTORE_PASSWORD`。这些私密签名材料没有放进交付包。正式版版本名为 `3.3.<Actions运行号>`。

如果 Actions 提示缺少签名文件或密码，打开该次构建的“检查正式签名”步骤查看具体缺少哪一项；不要使用体验版签名替换正式签名。
