# 捞捞课程表 · 安卓原生重排 3.4

这次以网站原有使用习惯为依据重新组织 App。应用、桌面小组件和备份文件的产品名称恢复为「捞捞课程表」，保留原来的图标、账号与存储结构。网页文件没有修改。

## 安装和更新

- `捞捞课程表-原生新版.apk` 是可以直接安装的原生体验包，版本 `3.4.12-preview`。它可覆盖此前同签名的体验包，正式版和体验版的本地数据分别保存。登录网站原账号可连接已有班级与云端记录。
- 要覆盖手机上原来的正式版，请使用下面的源码更新包，让 GitHub Actions 沿用仓库原签名生成正式 APK；不用卸载旧正式版，也不用替换签名文件。

## 上传 GitHub

1. 解压「捞捞课程表-安卓原生重排覆盖更新包.zip」。
2. 打开 `hangyuan2024-hue/class-calendar` 的 Code 根目录，点击 Add file → Upload files。
3. 把解压后的 `android`、`.github` 和 `docs` 文件夹拖进上传区域，保留文件夹结构，同名文件覆盖。不要把外层更新包文件夹或 ZIP 文件作为代码上传。
4. 点击 Commit changes。到 Actions → 安卓 App，等待成功；如未自动触发，可点 Run workflow。
5. 在成功记录的 Artifacts 下载 `class-calendar-3.4.*`，解压取得 `class-calendar.apk` 并安装。工作流也会更新仓库 `download/class-calendar.apk`。

说明文档、预览 PDF 和更新清单供你查看，不影响程序运行。更新包只有安卓代码、安卓打包流程和验证文档，没有网页首页代码；网站现有统计功能不受本次更新影响。仓库已有的 `android/release.jks` 与 Actions 的 `KEYSTORE_PASSWORD` 沿用现有配置，更新包不包含任何签名密钥。

## 使用方式

- 底部固定「首页、作业、日历、工具、我的」。左上菜单保留「班级墙、规划、问答、成长、班级」等网站入口；工具旁「快捷」可以直接选择常用工具。
- 首页只展示一套卡片。今天的课程与事项集中排列，记事入口一直存在。本周作业、本周事项、今日打卡按真实记录显示完成比例。
- 日历上方直接点「粘贴导入」：粘贴班群消息 → 整理并核对 → 修改或勾选结果 → 保存到我的事项。有班级发布权限时可以发布到班级。
- 日历里的「记一件事」使用选中的日期；首页记事使用今天。完整课表可直接打开，拍照识别、添加课程和导出订阅收进更多操作。
- 顶部日历小人是网站原来的捞捞形象。点击后查看轻重缓急提醒、查询课程/作业/打卡、直接完成事项。我的 → 提示小人设置可以收起首页提醒，顶部仍可打开。
- 首页常用工具的加号可以勾选真实工具，与工具页和快捷面板共用同一份选择。工具初次打开只显示常用项和分类，不再堆满所有功能。
- 我的 → 皮肤与首页提供 10 种配色。现有学习记录、用户卡片顺序及十项手机能力继续保留。
