# 捞捞校园 · 原生与元宇宙更新

修复快捷工具卡片：按钮按内容计算占用网格行数，不再用固定一行高度居中裁切。桌面导航提供收起／展开按钮并保存选择；手机底部导航保持可操作。删除新工作台里“我的校园 / WORKSPACE / AT A GLANCE”等标签，保留用户主动选择的外观。

赛博外观采用深空蓝、冰青操作色和克制的星空背景，统一导航、内容、快捷工具、表单与工具模组。静态背景避免持续扫描／闪烁，支持减少动画设置。

网页实验室与安卓原生工具均使用实际输入的本地记录。没有填入示例任务、模拟同学或虚构排行榜。两端提供相同schema的JSON备份，可手动交换；不会自动与原有班级或插件记录同步。

## 安卓实现

`MainActivity`是原生Java/Android控件界面：原生滚动区域、卡片、底部导航、输入表单、日期/时间选择、复习、计时与统计。首页和十项工具不创建WebView，断网可使用。数据存在应用私有SharedPreferences中；系统自动备份关闭，用户可通过系统文件选择器主动导出/导入。

`CloudActivity`为明确标注的班级云服务兼容入口，沿用已有网站账号与同步服务。它仍使用内置WebView，这部分没有宣称改成原生。站内导航按HTTPS、域名、端口和目录边界判断；主页面站内跳转保留在App中。外部链接不会直接启动浏览器，需确认；资源/iframe导航不会唤起外部应用。旧WebView回调同样确认外链。

专注计时按持久化截止时间运行，进入后台/进程重启后可恢复；启动与系统重启恢复提醒。系统省电机制可能延迟通知，界面按截止时间结算。导入备份会先验证格式，清除旧计时，再由用户确认替换实验室记录。

## 构建与更新

- 正式版：`gradle -p android assembleStableRelease`，路径`android/app/build/outputs/apk/stable/release/app-stable-release.apk`。
- 共存体验版：`gradle -p android assemblePreviewDebug`，applicationId为`com.laolao.classcalendar.preview`，不会覆盖旧应用。
- GitHub安卓工作流已切换正式variant及2.0版本名，使用原有`release.jks`和`KEYSTORE_PASSWORD`。要覆盖旧版，必须保持原签名；安装包不同签名时不能直接升级。
- 工作流在原签名配置缺失时会停止，不向正式下载目录发布临时签名包。
- 本次交付的体验APK采用单独体验签名。没有把体验签名包替换到网站的正式下载入口，也没有发布到GitHub。

兼容安卓7.0及以上；华为HarmonyOS兼容安卓的机型按Android执行。纯鸿蒙NEXT不支持这个APK，需要独立ArkTS工程。当前没有华为型号与实机，不能把Android模拟器验收等同于华为实机验收。

## 验收

实际APK已编译、签名校验，并在Android9（API28）的AOSP模拟器安装运行。原生截图来自已安装APK的系统截屏，界面层级验证主界面没有WebView。具体测试记录见本目录的验收摘要与截图。

网页在清爽、元气、赛博三种外观的320／390／768／1440像素下检查布局、快捷按钮边界、侧栏保存，以及实验室任务/晶片/复习/计时交互。补充检查拒绝无效或包含非法ID的备份。

真实账号登录、云同步和华为硬件未在此次本地环境测试。当前交付属于本地代码、APK和更新文件，不代表线上网站与正式下载包已发布。

新手安装与仓库导入步骤见[安装与导入](安装与导入.md)。`checks/LogicCheck.java`验证站内地址边界和严格日期／时间；`checks/BackupCheck.java`验证真实备份与非法ID、日期、优先级、重复记录、预算、统计及卡片级别。
