# 第三版：安装与导入

## 先在手机体验

1. 将「捞捞校园-原生安卓-体验版.apk」下载到手机，在文件管理器中打开并按系统提示安装。
2. 打开新图标「捞捞原生体验」。它和原来的 App 共存，不需要卸载旧 App。
3. 首页、航线、元宇宙的十个工具使用安卓原生界面，可断网使用。首次进入没有虚构的任务与记录，点击添加后即可保存。
4. 「我的」可以导出／导入学习备份；「班级云服务 · 联网入口」保留原网站的账号与班级服务。这部分使用 App 内的网页兼容界面。实验室本地记录和班级记录相互独立，不会自动同步。

体验版用单独的包名和签名，因此不会覆盖旧 App。需要原包名正式升级时，请按下一节更新仓库，通过原签名构建。

支持安卓7.0及以上，以及支持安装安卓APK的华为系统。HarmonyOS NEXT不能安装此APK。目前没有华为实机，不能承诺全部机型已通过验证。

## 更新现有 GitHub 仓库

当前基线是仓库 main 的 `1835292`（第二版已上传）。本次更新尚未替你推送到 GitHub；下载源码包后再导入。

1. 下载并解压「捞捞校园-V3-覆盖更新包.zip」。包内文件要覆盖到项目的根目录，也就是原来有 `index.html`、`app.js`、`android` 的这一层。
2. 在原项目中覆盖同名文件，保留 `android`、`.github`、`docs` 目录结构。不要把 ZIP 本身当成源码上传，也不要在仓库外再套一层文件夹。
3. 如果使用扣子编程，把解压后的文件覆盖到现有项目，再使用你原来的 GitHub 提交流程。若直接使用 GitHub 网页，请进入原仓库，用 Add file → Upload files 上传解压后的文件和文件夹，确认列表显示 `android/app/...`、`.github/workflows/android.yml` 等正确路径，然后提交到 main。
4. 保留原仓库的 `android/release.jks` 和 Settings → Secrets and variables → Actions 内的 `KEYSTORE_PASSWORD`。更新包没有包含或修改签名文件；不要重建签名。
5. 在 GitHub 的 Actions 打开「安卓 App」工作流。修改 android 文件后会自动运行；也可点 Run workflow，选择 main。
6. 工作流成功后，新的正式 APK 会写入 `download/class-calendar.apk`。再从网站下载入口安装此正式版，即可使用原包名更新。网站上线由仓库原来的 GitHub Pages 发布流程处理；等待对应发布任务成功。

如果构建提示缺少签名配置，恢复原来的配置再重新运行。工作流会停止，不会把临时签名 APK 放进正式下载入口。

「V3-完整源码.zip」供整项目导入和代码审阅使用。它不包含签名文件或已有二进制安装包；对现有项目更新，优先使用覆盖更新包。

## 网页上怎么使用

- 电脑左上方的「收起侧栏／展开侧栏」按钮可切换导航，并记住选择。手机保留底部导航。
- 原来底部快捷工具区按实际内容撑开，不再隐藏第一排。
- 「我的」外观里选择元气或赛博。元气界面已删除多余英文标签；选择赛博或进入元宇宙即可使用新外观。
- 元宇宙空间新增十个工具，填写自己的记录即可使用。导出 JSON 备份，可在安卓体验版「我的」里手动导入；导入会替换实验室本地记录，先保存原备份。
- 如浏览器仍显示旧界面，等待发布完成后刷新；必要时关闭旧标签页后重新打开。

## 本次实际验证

网页：清爽、元气、赛博，320／390／768／1440像素，快捷区边界、侧栏保存、实验室交互与非法备份拒绝。

安卓：已编译并签名的真实 APK，在 Android9（API28）模拟器安装运行，验证原生首页、任务保存与进程重启恢复、专注恢复／暂停／重置、外观切换、小屏导航，以及新增工具界面。截图与验收摘要见同目录。

未验证项：华为硬件、真实账号登录和班级云同步。网站与正式下载包在你提交并构建发布成功后才会更新。
