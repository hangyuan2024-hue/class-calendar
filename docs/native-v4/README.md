# 捞捞校园 · 原生完整版

这次交付的是 Android 原生应用：课程表、表单、日历、工具和元宇宙由 Android 控件与 Canvas 绘制，启动后进入 App 自己的界面。主要页面不加载网页，也不需要打开浏览器。

## 你先做哪一步

**先安装“捞捞校园-原生完整版-体验版.apk”试用，再用覆盖更新包更新 GitHub。**

| 文件 | 用途 |
| --- | --- |
| 捞捞校园-原生完整版-体验版.apk | 直接装到手机体验，桌面名称为“捞捞原生体验” |
| 捞捞校园-原生完整版-覆盖更新包.zip | 更新现有 GitHub 仓库，生成沿用旧签名的正式 App |
| 捞捞校园-原生完整版-Android源码.zip | 独立保存完整 Android 工程，供开发者继续维护 |

体验版使用独立包名，可以与旧 App 同时安装。它不能直接覆盖旧 App，也不会自动读取旧 App 私有目录里的资料。不要为了试用而卸载旧 App。

## 一、直接在手机安装体验版

1. 下载 APK 到手机。在微信等软件里下载时，可保存后通过手机“文件管理”打开。
2. 点开 APK，根据手机提示允许这个下载来源安装，完成后打开“捞捞原生体验”。
3. 进入“我的”，登录原网站账号；也可以先使用离线工具。班级功能需要登录并选择班级。
4. 进入“工具”，检查课程表、考试倒计时、花销记账和错题本。进入“手机专属”体验十项手机功能。

支持 Android 7.0 及以上的 APK 环境；Android 兼容版的华为系统可安装。纯鸿蒙 HarmonyOS NEXT 需要单独的鸿蒙工程，不能通过 APK 安装。

## 二、更新 GitHub，生成正式 App

仓库：<https://github.com/hangyuan2024-hue/class-calendar>

1. 在电脑解压“覆盖更新包”。打开解压后的文件夹，里面应看到 **`.github`、`android`、`docs`**。
2. 打开仓库首页，确认选择的是 `main` 分支，点击 **Add file → Upload files**。
3. 把上述三个文件夹拖进上传区域。**保留文件夹层级；不要再套一层“覆盖更新包”文件夹；也不要把文件全部摊平到根目录。**
4. 同一路径的文件会覆盖旧文件。填写提交说明，例如“更新原生完整版 App”，点 **Commit changes**。
5. 打开仓库的 **Actions**，选择 **安卓 App**，等待最新的一次任务变成绿色。
6. 下载这次任务页面底部的 `class-calendar-3.0.…` 压缩包并解压，手机安装里面的 `class-calendar.apk`。构建成功也会更新仓库的 `download/class-calendar.apk`。

目录应是这样：

```text
class-calendar/
├── .github/workflows/android.yml
├── android/app/build.gradle
├── android/app/src/main/AndroidManifest.xml
├── android/app/src/main/java/com/laolao/classcalendar/…
├── android/app/src/main/res/…
└── docs/native-v4/…
```

更新包保留你现有的稳定版构建方式，并沿用仓库已有的 `android/release.jks` 和 Actions 中的 `KEYSTORE_PASSWORD`。**不要删除原签名文件，也不要生成一个新签名替换它**，否则无法直接更新旧 App。交付压缩包不包含签名私钥。

这次没有修改网站的 `app.js`、`index.html`、侧边栏修复或电脑版工程。不要删除仓库原来的其他文件。GitHub 网页上传支持隐藏的 `.github` 文件夹；若文件管理器看不到它，先开启“显示隐藏文件”。

## 四、十项手机专属功能

入口：**工具 → 手机专属**。

| # | 手机功能 | 实际用途 |
| --- | --- | --- |
| 1 | 桌面今日安排小组件 | 在手机桌面查看课程与待办，直接进入课程或快速记事 |
| 2 | 系统课程/截止提醒 | 使用 Android 通知与定时任务提醒课程、作业和个人事项 |
| 3 | 跨 App 分享收件箱 | 从其他 App 分享文字和图片，整理为任务或错题 |
| 4 | 语音速记 | 调用手机已安装的语音识别服务，把识别结果放入可编辑事项 |
| 5 | 课堂录音 | 真实 AAC 录音、后台录音通知、停止与播放；单次最长30分钟 |
| 6 | 日记设备隐私锁 | 使用系统指纹/生物识别或手机锁屏密码验证；锁定日记页面禁止系统截屏 |
| 7 | 上课自动勿扰 | 用户开启后按课表设置勿扰，并在结束时恢复此前状态 |
| 8 | 校园地点便签 | 保存地点、获取一次当前位置、计算距离、主动打开地图导航 |
| 9 | 拍照资料扫描 | 拍照/选图、旋转与裁切、灰度处理、多页 PDF 导出 |
| 10 | 校园电话快捷拨号 | 选择单个联系人或手动添加，调用系统拨号界面 |

小组件需要桌面支持。语音识别、指纹和地图使用手机提供的服务；没有相应服务时可用文字输入、设备密码或手动坐标。系统权限只在使用对应功能时申请。

通知需要允许 App 通知。课程提醒使用系统定时机制，休眠、省电或华为后台管理可能让提醒延后；可以在手机设置中允许 App 后台运行。不能据模拟器测试保证华为每个型号的后台提醒行为。

## 五、捞捞元宇宙

深蓝背景、青色高对比按钮、原生绘制的星球和轨道、可触摸的学习卡片。经验值、等级、每日任务、12枚原有徽章与校园小百科都使用实际学习记录。

十个学习入口：星轨冲刺、任务航线、记忆晶片、倒计时信标、复习雷达、能量补给、课程导航、心情黑匣子、校园装备、时空回放。它们分别进入能保存、编辑和复习的功能页面。

## 六、资料怎么保留

- 先在旧 App/网站里做好备份。登录同一个账号后，可通过“我的 → 同步”读取原系统已上传的个人事项、打卡、规划、成长和主题等数据；课程沿用原来的课表接口。
- 在“我的 → 数据备份”可导出学习数据，或导出包含照片和录音的完整备份；通过系统文件选择器保存到你选择的位置。
- 完整备份最多32MB，其中附件合计最多18MB、单个附件最多12MB。较大录音可以单独分享导出，再导出学习数据。
- 恢复前核对所选账号。恢复成功后会暂停云端同步，供你确认内容，再手动开启同步。文件校验不通过时不会覆盖现有学习数据。
- 提供“迁移上一版工具记录”入口，导入上一版原生工具 JSON 中可识别的事项、考试、费用、复习卡片、清单和日记。浏览器各插件自定义格式需要分别核对，不能保证任意旧 JSON 自动完整转换。
- 新增插件学习记录、录音、照片、地点和电话保存在当前设备的账号空间；完整备份可带走附件。原网站的云端接口没有覆盖这些全部新字段，不应把登录账号当作所有附件都已云备份。
- 离线模式下可使用个人学习工具。班级墙、管理操作、云端 OCR 和云端 AI 需要网络与相应权限。照片 OCR 会上传你主动选择的图片供原服务识别，结果先显示为可编辑课程，再确认保存。
