# 捞捞校园网站 · 第二版设计

本次重新设计网站的信息结构与视觉体系：纸白底色、深墨色导航、蓝紫操作色，以及薄荷绿、杏橙色的辅助信息。已有账号、班级数据、个人事项与插件接口继续使用。

## 页面与使用体验

- 产品首页重新搭建为完整的校园产品入口：功能价值、可操作示例、使用步骤、客户端下载、常见问题与账号登录。移除原先的长滚动演示脚本，首页保持在首屏，用户点击登录入口后再进入表单。
- 工作台采用桌面侧栏、主学习空间和校园速览。问候与近期日程并列，作业与工具按层级组织，手机保留底部导航。首页自定义、原有动态数据和主题选择继续可用。
- 登录、客户端下载、班级管理和开发者页面统一布局、表单与控件。
- 内置课表与个人日记网页接入相同视觉规范；插件样式保留在 HTML 内，符合原沙箱的样式限制。
- 首页课表、待办和计时器均为明确标注的界面示例。示例交互只在当前页面运行，不会写入真实账号。

## 可访问与设备适配

首页示例选项卡支持方向键、Home 和 End；待办和计时器支持键盘操作。登录表单切换提供选中状态和键盘切换，输入提示关联到表单字段。保留可见焦点，支持减少动画设置。新版主操作使用清晰的文字名称。

## 截图与验收

此目录中的截图来自实际网页的 Chromium 渲染。首页示意明确标注，工作台和工具截图使用空白的本地访客环境。

验收包括 63 项主要页面布局与本地交互检查、12 项正常浏览器上下文的错误与资源检查，以及 53 项课表／日记布局、弹窗与隔离运行检查。六种主页面宽度为 320、360、390、768、1024、1440 像素；工具另检查亮暗模式和 320、390、1440 像素。独立浏览器错误检查及插件检查均无未捕获错误。主要页面本地资源没有缺失。另外，班级与插件后台在本地模拟管理员下通过 14 项布局检查，后台写入未测试。

测试将外部请求拦截，仅对本地数据操作。真实账号登录、邮件、云同步和管理员权限写入需要账号环境核验。具体验收摘要见 `verification.json`。

## 代码范围

主要新增文件：

- `studio-v2.css`：产品首页布局与视觉。
- `landing-v2.js`：首页的本地示例交互。
- `embedded-auth-v2.css`：首页嵌入的原账号表单及引导样式。
- `workspace-v2.css`：日常工作台与各工具的视觉。
- `auxiliary-v2.css`：登录、下载及管理页的视觉。

网页改版与客户端安装包是独立的交付范围。安卓客户端加载现有网站；Windows 客户端使用独立的 renderer 页面，小程序也有独立实现，此次没有重新打包或修改它们的独立界面。

Service Worker 的静态缓存已升级，新增样式与脚本使用版本号引用。将变更上线后，需要检查实际域名的页面和缓存更新。
