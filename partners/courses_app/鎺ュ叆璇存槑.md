# 「课内」接入捞捞课程表的说明

这个文件夹是合作队伍「课内」的原始代码（来自 https://github.com/RainyyyyDay/courses_app ，提交 c0fec13），原样保留，方便对照和继续开发。
**网站上实际运行的是接入后的版本，不是这里的代码。** 这里的前端连的是本机 `localhost:3000` 的 Node 后端，放在网站上不会生效。

原仓库里的 `back/db/data/app.db`、`back/data/backups/*.db`、`back/uploads/*.jpg` 是个人数据，没有复制过来。

## 接入后的样子

| 原来（课内） | 接入后（捞捞课程表） |
| --- | --- |
| `fronted/` 原生页面 | `study.js` + `study.css`，网站里的「学习」页（侧栏「学习」、首页「课内学习」、工具页顶部入口） |
| Node + Express 接口（`back/server.js`） | 数据库函数 `kn_*`（`deploy/study.sql`），用捞捞的登录身份，只能读写自己的数据 |
| SQLite 表 courses / materials / notes / assessments / mistakes | `kn_courses`、`kn_items`（kind 区分资料 / 笔记 / 考核 / 错题） |
| knowledge_nodes + 三张关联表 | `kn_nodes` + `kn_links`（一张表管所有资源的标签） |
| 上传文件存在 `back/uploads/` | 附件存在数据库 `kn_files`（单个 ≤ 5MB，每人 ≤ 100MB） |
| 没有登录，数据只在一台电脑上 | 跟着捞捞账号走，换设备都在，一台设备改了别的设备几秒内更新 |

功能对应：课程添加 / 搜索 / 改名 / 置顶 / 删除；资料、笔记、错题的上传和手动输入、改名和标签（文件后缀固定不能改）；考核的截止日期、要求和附件；
知识框架的分类 / 知识点新建、改名、删除、上移下移、移到别的分类下（防止移进自己的下级）；分类详情汇总下级知识点的内容；系统分类「未分类」收纳没打标签的资源。

新增的打通：课程可以从「课程表」一键导入；有截止日期的考核会出现在首页、日历、作业提醒里，可以勾完成、加到手机日历。

原版的拖拽排序在网站里换成了「⇅ 移动」菜单（上移 / 下移 / 移到…），手机上也好用。
