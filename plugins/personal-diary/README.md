# 个人日记模块（Personal Diary）

## 1. 模块说明
这是“班级群信息整理助手”中的个人日记模块。模块为独立 HTML 页面，无需后端即可运行，适合直接嵌入或接入现有前端项目。

## 2. 主要功能
- 每个自然日对应独立日记，默认打开当天。
- 支持前一天、后一天、日期选择器和“今天”按钮切换日期。
- 日记内容自动保存，切换日期前会先保存当前内容。
- 支持历史日记列表与字数统计。
- 支持浅色/深色系统主题和移动端适配。
- 日记正文优先使用浏览器 Web Crypto API 的 AES-GCM 本地加密保存。
- 所有本地存储键统一使用 `personal_` 前缀。
- 支持天气记录：
  - 今天：可查询并保存当前选择城市的当天实时天气。
  - 历史日期：若已有天气记录，优先恢复该日已保存的城市和天气。
  - 历史日期无天气记录时，不自动猜测城市；用户可手动选择城市，再查询该城市在该历史日期当天的天气。
  - 历史日期可主动修改城市，修改后会重新查询该城市在该日期当天的天气并覆盖该日天气记录。
  - 支持浏览器定位；定位只在用户主动授权后使用。

## 3. 数据存储
数据仅保存在当前浏览器的 `localStorage` 中，不依赖服务器数据库。

主要键包括：
- `personal_diary_YYYY-MM-DD`：某日日记正文
- `personal_diary_weather_YYYY-MM-DD`：某日天气快照
- `personal_diary_key`：本地 AES-GCM 密钥材料
- `personal_diary_meta`：日记日期与最后更新时间元数据
- `personal_weather_city`：最近使用城市
- `personal_weather_lat` / `personal_weather_lon`：最近使用城市坐标
- `personal_weather_cache`：天气缓存

注意：清除浏览器站点数据、localStorage 或更换浏览器/设备后，本地日记数据不会自动同步。

## 4. 天气服务
天气与城市查询使用 Open-Meteo 相关接口；浏览器定位后的城市名称解析使用公开反向地理编码接口。天气功能需要联网，但天气接口失败不会影响日记输入和本地保存。

## 5. 运行方式
直接用现代浏览器打开 `index.html` 即可运行。

建议浏览器：
- Chrome / Edge
- Android Chrome
- Safari（支持 Web Crypto 的版本）

## 6. 集成建议
如果接入主项目，可将 `index.html` 作为独立页面接入路由，或拆分其中的 HTML/CSS/JS 后并入现有前端结构。

集成时请保留：
- `personal_` 本地存储前缀
- 日期独立存储逻辑
- 天气按日快照逻辑
- Web Crypto 加密逻辑

## 7. 交付前建议测试
1. 今天输入日记，刷新后内容仍存在。
2. 输入后立即切换日期，再切回来，内容不丢失。
3. 20 日保存日记和天气，21 日保存另一份，再回 20 日仍恢复 20 日天气。
4. 历史空白日期不自动生成天气，手动选城市后可生成该日期当地天气。
5. 历史日期手动修改城市后，只覆盖该日期天气，不影响其他日期。
6. 拒绝定位后仍可手动输入城市。
7. 断网时日记仍可正常输入和保存。
8. 检查 localStorage，日记正文不应直接以明文显示（支持 Web Crypto 时）。
