# 捞捞PPT助手

让老师自己的 **公仔分身**（老师的样子、老师的声音）出现在 PPT 里：进到某一页时形象自动开讲；页面上放几个问题按钮，点一下跳到回答页，由形象回答，点「返回」回来。

任何老师都能用：上传自己的照片和一段录音，就生成自己的形象。全部在自己电脑上完成，不联网。

## 四步

1. **我的形象**（推荐 **AI 形象**，要 NVIDIA 显卡）：AI 照着老师的照片画出又像本人、又可爱的 Q版形象（一次 4 张，挑最好的），再让它开口讲课。三种用法：
   - **AI Q版动画**（推荐）：AI 在同一张图上再画「张一点嘴、张大嘴、闭眼」三张，我们自己写的 2D 动画（`renderer/puppet.js`）让它跟着配音换口型、眨眼、点头、挥手、指幻灯片、歪头想一想。出视频和公仔风一样快，形象画好以后就不再需要显卡。
   - **AI 说话视频**：同一张形象 + 配音，由 AI（InfiniteTalk）生成整段视频，表情、口型、手势都是 AI 画的，最自然；很慢（16G 显卡大约 2～3 分钟出 1 秒），适合下班前点开始。
   - **3D 手办**：挑好的图交给下面的「AI 生成 3D 形象」做成 3D 模型。
   全部在老师自己电脑上跑（本机的 ComfyUI，只听 127.0.0.1），照片和录音不出这台电脑。做法见下面「AI 形象」。
   没有显卡的老师用 **公仔风**：老师在电子世界里的**公仔分身**（2026.11 公仔风）：像桌上摆的 3D 手办——大头、黑色高马尾扎红发圈、一缕缕有厚度的刘海，瓷白的脸上是粗眉毛、眯眯笑眼、桃色腮红和小嘴，会眨眼、说话时嘴跟着声音张开、挥手时笑开；穿黑色白格子高领毛衣、紫色裤子、棕色短靴，肉乎乎的公仔手（想要机器人骨架可以勾上「机器人骨架」）。像拍手办一样打光：柔光环境 + 斜上方主光（刘海、头在脸上和脖子上有软软的影子）+ 背后的轮廓光，看着是立体的。上传一张正面照片，程序**自动找到两只眼睛和嘴**（MediaPipe 人脸网格，本机跑；找不到或者不准时老师在照片上点三下），量出老师的五官特点（两眼的距离、眉毛的粗细和走向、嘴的宽度和笑的弧度），照着画到公仔脸上；戴眼镜就勾上「戴眼镜」；还会**认出发型**（头发长短、齐刘海 / 斜刘海 / 中分、有没有扎起来、卷不卷）和头发、上衣的颜色，直接套到 Q版公仔上（认不准可以改）。照片本身不贴上去。
   **上传视频（更像）**：老师用手机拍 10～30 秒——看着镜头说一句话、停 3 秒、左右转头、转过身背对一下。程序逐帧认脸，自动挑最清楚的正脸（当照片）、两边侧脸、后脑勺（认马尾 / 丸子头），截 3～10 秒说话的声音当配音参考（说的话已经填好），再把正对镜头的那几秒裁成竖的 720×1280 当「真人数字人」的模板。
   **真人数字人**（有 NVIDIA 显卡）：「脸的样子」选「真人数字人」，讲解视频就是老师自己（视频模板来回放），嘴跟着配音动——用 LatentSync 1.5 对口型，人脸检测换成了 YuNet（没用只许非商业使用的 InsightFace），见 [`ai3d/README.md`](ai3d/README.md)。
   **授权和标识**：上传照片、视频、声音之前要先同意「人脸和声音的授权」（本人，或者写上对方名字、确认已取得书面同意），记录在本机；「清除我的照片、视频和声音」一键全删并撤回授权。按《人工智能生成合成内容标识办法》和 GB 45438-2025，所有讲解视频画面左上角一直有「AI生成」（字高约为短边的 6%），mp4 元数据里写 `AIGC` 隐式标识（附录 E 的 JSON）。发型、刘海、衣服颜色都能改，点「吸颜色」再点照片，衣服颜色就和照片里一样；「脸的样子」里还能换成机器人屏幕脸或照片脸。「导出成捞捞编程皮肤」把形象存成皮肤文件，捞捞编程里能直接导入。右边是 3D 预览，能试所有动作：挥手、指幻灯片、边讲边比划、点头、托腮想一想、说话。讲解视频是竖的 9:16，公仔从头到脚都在画面里，脸大，放在 PPT 角落里也看得清。
   **AI 生成 3D 形象**（有 NVIDIA 显卡的老师，「我的形象」页最下面）：老师照片定长相、参考图定风格，在自己电脑上用 AI 画出几张公仔立绘，挑一张最像的（已经有满意的公仔图可以直接用）；再用 AI 把它做成带贴图的 3D 模型，自动绑骨骼，让眼睛和嘴会眨、会说话。做好以后「脸的样子」选「AI 3D 形象」，挥手、指幻灯片、托腮、说话、导出视频都和公仔风一样。用的是 Qwen-Image-Edit-2509（4bit）+ Hunyuan3D-2，整合包要老师自己下（推荐 Hunyuan3D-2 WinPortable），第一次要下载约 40G 模型；绑骨骼和做脸是我们自己写的，不用显卡。详细的做法见 [`ai3d/README.md`](ai3d/README.md)。
2. **我的声音**：上传一段 3～10 秒的录音，写上录音里说的话。声音克隆用 [GPT-SoVITS](https://github.com/RVC-Boss/GPT-SoVITS)（本机运行，需要 NVIDIA 显卡）：下载它的 Windows 整合包，解压到英文路径，在软件里选那个文件夹、点「启动」。也可以不克隆，每一段都上传自己的录音。
3. **选页和内容**：打开一个 .pptx，勾上要加形象的页。每页先帮你打好讲解词和两个问题的草稿（从标题和要点来），改成你想说的。每一段还能选动作：自动、挥手打招呼、指着幻灯片、边讲边比划、点头、先想一想。
4. **生成 PPT**：选形象放在右下角还是左下角、多大，点「开始生成」：每一段配音 → 画出形象说话的竖版视频（嘴跟着声音张合；按选的动作动，选「自动」就是：第一页开头挥手、讲到一段指着幻灯片、其余边讲边比划；回答前先想一想、说完点头）→ 写进一个新文件「原名（捞捞助手）.pptx」，原文件不动。

## AI 形象（本机 ComfyUI）

| | 用什么 | 许可 | 显存 | 第一次下载 |
|---|---|---|---|---|
| 画 Q版形象、口型和眨眼图层 | Qwen-Image-Edit-2511（fp8）+ 4 步加速 LoRA | Apache-2.0 | 12G 起（内存 32G 起，不够的部分 ComfyUI 自动放内存） | 约 31G |
| AI 说话视频 | InfiniteTalk（Wan2.1-I2V-14B 的 GGUF 量化版）+ lightx2v 加速 LoRA | Apache-2.0 | 12G 起；按显存自动挑量化（24G Q8、16G Q5、12G Q4）和换出的块数 | 约 23G |

- 老师自己下 **ComfyUI 的 Windows 整合包**（官方 `ComfyUI_windows_portable`），解压，在软件里选那个文件夹、点「启动」。软件用整合包自带的 Python 启动它，只听 `127.0.0.1`，也能连一个已经开着的本机 ComfyUI。
- 缺什么软件里直接点：**下载模型**（国内走 hf-mirror.com，断了接着下，按显存挑文件）、**装插件**（说话视频要用的 ComfyUI-WanVideoWrapper、ComfyUI-VideoHelperSuite，固定版本，从 GitHub 下 zip，国内走加速镜像，依赖用清华 / 阿里的 pip 源）。
- 工作流在 `core/workflows.js`（API 格式的节点图）。节点名、参数、取值都拿真的 ComfyUI 0.45 + 两个插件的固定版本核对过：`node test/workflows-check.js http://127.0.0.1:8188`（不要显卡：在 models 文件夹里放同名空文件就能过校验）。**换 ComfyUI 或插件版本以后要重新跑一遍。**
- 画风三种：盲盒手办（默认）、3D 动画电影、日系动漫；提示词要求「保留本人的脸型、发型和发色、眉毛、眼型、胡子、眼镜、肤色、衣服」，再加大头 Q版比例、白底全身站姿。老师可以补一句「哪里不像」。
- Q版动画：`puppet.js` 先把三张图层和原图对齐（AI 改图会挪几个像素）、找出变了的那块（嘴 / 眼睛）、找脖子；改动太大或者没改的图层不用，提示重画。播放时一个 WebGL 着色器画：头绕脖子转（头和身子之间渐变，不撕裂）、呼吸、侧身、轻蹦，背景换成这一页的颜色，脚下一圈软影子。
- 所有 AI 出的视频照样叠「AI生成」、写 `AIGC` 元数据；「清除我的照片、视频和声音」也会删掉 AI 形象的候选、形象和图层。
- **还没在真显卡上跑过**：画出来像不像、好不好看，说话视频的效果和速度，要在有 NVIDIA 显卡的电脑上试了才知道；提示词和参数可能还要调。

## 写进 PPT 的是什么

- 选中的页：右下角一个视频（形象 + 老师的声音），**进这一页自动播放**（这一页本来有动画也不影响，原来的动画照旧）；旁边竖着排几个圆角的问题按钮。
- 每个问题一张**隐藏的回答页**，插在原页后面：上面是问题和回答的文字，右边是形象回答的视频（自动播放），左下角「← 返回」回到刚才那页。隐藏页正常放映时不会出现。
- 视频是 H.264 + AAC 的 mp4，PowerPoint 2013 以后都能放；背景色跟着这一页的背景。

## 代码

| 路径 | 做什么 |
|---|---|
| `main.js` / `preload.js` | Electron 主进程；界面只能 `cc.call` 调 `core/service.js` 里的方法 |
| `core/service.js` | 后台：老师资料（`%APPDATA%\LaolaoPPT\profile.json`）、配音、视频、生成 |
| `core/pptx.js` | 读写 .pptx（它是 zip + XML）：读每页文字和背景色；加视频、自动播放、按钮、隐藏回答页 |
| `core/voice.js` | GPT-SoVITS：认整合包、用它自带的 Python 跑 `api_v2.py`、`/tts` 要 wav |
| `core/media.js` | 读 wav、算口型（每 1/25 秒的响度）、ffmpeg 合成 mp4（ffmpeg 随安装包带）、叠「AI生成」标识（`core/assets/ai-label.png`）和写 `AIGC` 元数据；视频抽帧、截声音、裁真人模板 |
| `core/draft.js` | 讲解词和问答的草稿 |
| `renderer/avatar3d.js` | 老师分身（three.js）：形象数据 → 3D 公仔（默认；动画骨架：胯、腰、胸、头、肩肘腕、手指、膝踝）、AI 生成的 3D 形象（`loadAi` 读 avatar.glb，`buildAi`：IK 摆胳膊、脸上的画布画眼睛和嘴）或机器人屏幕脸 / 照片脸、6 种动作、说话的嘴；`frame()` 一帧帧画，导出视频用 |
| `renderer/face.js` | 照片 → 脸：三个点求仿射变换转正对齐、卡通化（保边磨平 + 色阶 + 描边）、取皮肤色 |
| `renderer/vision.js` + `vision.html` | 认脸、认发型、给视频帧打分、截配音参考。MediaPipe face_mesh + selfie_segmentation（Apache-2.0，`npm run prepare-ui` 拷到 `renderer/vendor/mediapipe`）在 `vision.html` 这个小页面里跑（它的 wasm 胶水要 eval，只在这个页面里放开），主窗口用 postMessage 送图过去；认发型的算法是自己写的，纯数组，`test/vision.test.js` 用画出来的假人测 |
| `renderer/app.js` | 界面四步；导出视频时在界面里画好每一帧 png 送给后台 |
| `core/engine.js` | 本机 AI 引擎（ComfyUI）：认整合包、启动 / 连接（只认本机）、查缺的插件和模型、按显存挑模型文件、断点续传下载、装插件、交工作流、收进度（自己写的极简 WebSocket）、取结果、停止 |
| `core/workflows.js` | 交给 ComfyUI 的工作流：照片 → Q版形象、只改嘴 / 眼睛的图层、形象 + 配音 → 说话视频；要哪些模型和插件 |
| `renderer/puppet.js` | AI Q版动画：图层对齐、找嘴和眼睛、找脖子（纯数组，`test/puppet.test.js` 用画出来的小人测），WebGL 画每一帧 |
| `core/ai3d.js` | AI 3D 形象：认 Hunyuan3D-2 整合包、用它的 Python 跑形象工坊、收进度（`@@` 开头的 JSON 行）、一次只做一件、能停 |
| `ai3d/lao3d/` | 形象工坊（Python）：照片 + 参考图 → 立绘 → 3D 模型 → 自动绑骨骼 → 会动的脸 → `avatar.glb`，见 `ai3d/README.md` |

## 开发

```
npm install
npm run prepare-ui   # three.js → renderer/vendor
npm start            # 打开软件
npm test             # PPT 读写、声音、GPT-SoVITS（用假的服务）、后台（授权、视频、标识、一键清除、AI 形象）、AI 3D 形象（用假的工坊）、认发型、本机 AI 引擎（用假的 ComfyUI）、Q版动画
node test/workflows-check.js http://127.0.0.1:8188   # 拿真的 ComfyUI 核对工作流
npx electron test/electron-smoke.js 照片.jpg   # 在真的 Electron 里（file://、真的安全策略）试一次认脸认发型
python -m unittest discover -s ai3d/tests   # 形象工坊：找关节、蒙皮、做脸（要 numpy、scipy、opencv-python、pillow）
node test/ui-server.js 8899   # 在浏览器里跑界面（测试用，选文件用环境变量 PICK_PPTX 等）
# AI 3D 形象走一遍（没显卡）：PICK_AI3D_DIR=假整合包文件夹 PICK_AI3D_PY=python3
#   LAO3D_TEST_CANDS=几张 png 当画好的立绘 LAO3D_TEST_RAW=一个带贴图的 glb 当生成的 3D 模型
#   PICK_VIDEO=一段 mp4  LAO3D_TEST_TALK=1（真人数字人不跑模型，把模板接到配音那么长）
# AI 形象走一遍（没显卡）：先开假的 ComfyUI（test/fake-comfy.js），COMFY_URL=它的地址 PICK_COMFY=一个假的整合包文件夹
```

打包：`npm run dist` 出 `dist/LaolaoPPT-Setup.exe`；推到 main 后 GitHub Actions（`.github/workflows/ppt.yaml`）自动打包，发布在 Releases 的 `laolao-ppt`。
