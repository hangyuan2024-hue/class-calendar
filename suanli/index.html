LAOLAO GRID · OPEN

捞捞算力 通用版，
用自己的服务器搭训练网。

把实验室、宿舍里闲着的电脑连成一台「训练机」：每台电脑空闲时领任务，一台关机了，下一台从最近的存档接着算。通用版和捞捞团队自己的训练网完全分开，你的任务、数据、模型都在你自己的服务器上。

免费下载 ↓客户端：Windows 10 / 11 · 64 位
调度中心：Linux 云服务器，2 核 2G 就够
01 / HOW IT WORKS

一个训练网由三部分组成

调度中心装在你的云服务器上：派活、记账、存进度，带一个控制中心网页（看每台电脑实时跑到哪一行）。
管理员命令行在你自己的电脑上：生成配方签名的私钥、发邀请链接、签名配方、建任务。私钥只存在你电脑上。
客户端每台出力的电脑装一个：粘贴邀请链接加入，空闲时领任务、跑配方（Python）、定时上传存档。
⇄

一台停了，下一台接着算

每台电脑 20 秒报一次平安，2 分钟没消息，任务就交给下一台，从最近的存档接着算。支持拆小任务、接力训练、多台同时训练（DiLoCo）。

✓

配方必须签名

在别人电脑上运行的代码，必须由管理员的私钥签名（Ed25519），签名不对客户端就不运行。就算服务器被攻破，也没法让大家的电脑运行别的代码。

☾

对电脑主人友好

默认自己点「开始」才算；主人一用电脑就让出显卡；按显卡温度自动放慢；随时暂停、退出。

03 / SETUP

在服务器上搭调度中心

准备一台服务器

  • Linux 云服务器，2 核 2G 就够（Ubuntu 22.04 以上、Debian 12、CentOS Stream 9 都可以）
  • 在云服务商的控制台 → 防火墙，放行端口 8787
  • 有域名的话推荐用 HTTPS：先把域名解析到这台服务器，放行 80 和 443

上传压缩包，运行安装脚本

把下载的 LaolaoGrid-Open-Server.zip 传到服务器上（云控制台的「上传文件」或 scp 都行），在服务器上运行：

sudo mkdir -p /opt/laolao-grid-open
sudo unzip LaolaoGrid-Open-Server.zip -d /opt/laolao-grid-open
sudo bash /opt/laolao-grid-open/laolao-grid/server/deploy.sh

有域名时，最后一行换成这一行（自动申请 HTTPS 证书）：

sudo DOMAIN=grid.你的域名.cn bash /opt/laolao-grid-open/laolao-grid/server/deploy.sh

脚本会自动装 Node.js 22、设成开机自启，最后打印调度中心地址、控制中心（地址后面加 /admin/）和管理员口令。口令只留给自己，不要发给别人、不要截图。

在你自己的电脑上：生成签名密钥

装 Node.js 22 以上，把压缩包解压，进到 laolao-grid 文件夹：

node tools/grid.js login https://grid.你的域名.cn 管理员口令

这一步在你电脑上生成配方签名的私钥（不会上传），只把公钥告诉调度中心。

发邀请，让大家加入

node tools/grid.js invite 张三

把打印出来的邀请链接发给张三。他装好客户端、粘贴链接、勾选同意，按「任务向导」装好训练环境就能出力了。控制中心网页里也能发邀请。

试运行

node tools/grid.js job plans/demo.json

会建几个示例任务：测每台电脑的显卡、生成 + 人工审核、接力训练（关掉一台看下一台接着算）、多台一起训练。之后照着 recipes/demo_relay.py 写你自己的配方，用 node tools/grid.js job 你的计划.json 自动签名、上传、建任务。

以后更新

下载新版压缩包，解压覆盖原来的文件夹，然后 sudo systemctl restart laolao-grid。任务、租约、存档都在数据库里，重启后原样接着算。

04 / GOOD TO KNOW

用之前要知道

  • 通用版不带捞捞自己的训练配方和训练计划，只带示例；你的训练网里跑什么，由你写、你签名。
  • 只邀请你认识的人；要在别人电脑上运行代码，先征得对方同意（客户端加入时会让对方勾选同意）。
  • 服务器上的密钥（对象存储等）只在服务器上输入，不要发到聊天里。
  • 训练环境（Python、PyTorch）和 AI 组件从国内镜像下载，第一次要下几 G。
