# 捞小智（捞捞的智能体）入口

- 页面：`xiaozhi/index.html`（网址 `/xiaozhi/`）。按钮的地址和状态在根目录 `site-config.js` 的 `xiaozhi` 里改：
  `xiaozhi: { url: "https://……", status: "内测中" }`。`url` 留空时页面显示「内测准备中」，按钮点不了。
- 捞捞PPT助手左边栏的「捞小智」打开的就是这个页面，所以以后换地址只改 `site-config.js` 一处。

## 正式对外开放之前

捞小智在云端跑大模型、回答公众的问题，属于《生成式人工智能服务管理暂行办法》管的「生成式人工智能服务」。开放之前要先弄清楚：

1. **备案 / 登记**：自己训练或部署大模型对公众服务要做「大模型备案」；调用已经备案的大模型（比如在扣子 / Coze、豆包、通义等平台上搭的智能体）对外提供服务，一般要到所在省的网信办做「登记」。具体以所在地网信办的要求为准，内测（只给团队和少量受邀用户）阶段也建议先问清楚。
2. **标识**：回答是 AI 生成的，按《人工智能生成合成内容标识办法》要让用户看得出来（页面上已经写了「内容由 AI 生成，仅供参考」；智能体平台自己的对话界面一般也会标）。
3. **隐私**：对话会发到智能体平台。页面上已经提醒不要发身份证号、密码等；捞捞课程表的账号数据如果要接给智能体，要在隐私政策（`privacy.html`）里写清楚给了哪个平台、用来做什么。
4. **未成年人**：用户里有学生，要有未成年人保护的措施（使用时长、内容过滤由平台提供的要打开）。
